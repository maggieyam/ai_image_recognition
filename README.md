# Image Recognizer

Find out what's in a picture. Upload an image or paste a screenshot, and get a short plain-English description.

## How to use

1. Add an image in either of two ways:
   - **Upload** a file from your device
   - **Paste** from your clipboard with Ctrl/Cmd+V, for example a screenshot
2. Click **Describe image**.
3. Read the description under the button. It takes a few seconds.

## Good to know

- **Descriptions are short and general**, like a caption for a photo: "a brown bear walking across a rocky hillside". They can be wrong or oddly worded, especially for crowded scenes, and they don't read text in images.
- **Supported images:** common formats such as JPG and PNG, up to 16 MB. Very large images are shrunk before analysis.
- **Fair-use limits:** 10 requests per minute and 100 per day per visitor, so the free demo stays available to everyone.
- **The first request after a quiet period can be slow** while the demo wakes up.
- **Your images aren't saved.** They're processed in memory to produce the description.

## Run it yourself

Everything runs on your own computer, so there are no usage limits and your images never leave your machine.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:8000. The first run downloads about 1 GB of model weights. A GPU is used automatically if you have one; otherwise it runs on CPU.

> **Intel Mac:** PyTorch's last macOS x86_64 build is 2.2.2, which is why `requirements.txt` pins `transformers<5` and `numpy<2`. On torch older than 2.6 the model weights are converted once into a local `models/` folder.

## About

Descriptions are generated by [BLIP](https://huggingface.co/Salesforce/blip-image-captioning-base) from Salesforce. The app is a small Flask server (`app.py`) around the model (`recognizer.py`), with the page in `web/`.
